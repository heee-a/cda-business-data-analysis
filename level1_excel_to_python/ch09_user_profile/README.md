# 第9章 用户标签体系与用户画像专题（SQL → Python）

**教材素材**：`信用卡客户画像.sql`、`data/*.csv`、`信用卡客户画像.pptx`
**迁移脚本**：`01_customer_profile_tags.py`
**配套数据**：`data/level1/kdd99/*.csv`

## 标签工厂流程

以 `client_id` 为主键，把 7 张关系表聚合成宽表，再打 8 类标签：

1. **人口属性**：性别、年龄段（观察截至 1998-12-31）；
2. **地域经济**：按地区 GDP 三分位划分低/中/高；
3. **资产持有**：账户数、持卡数、持卡类型；
4. **风险状态**：是否存在 `status = B` 的贷款；
5. **交易行为**：转账金额与笔数分层；
6. **客户价值**：`log1p(转账金额) + 0.5 × log1p(贷款金额)` 三分位分层。

## 运行结果

- 生成 5,369 位客户的标签宽表；
- 客户价值高/中/低各约 1,790 人；
- 贷款状态：无贷款 4,542、正常贷款 796、有关注贷款 31。

##  vs 教材原 SQL

教材用多表 `LEFT JOIN` 与子查询生成画像；Python 版先按客户聚合再做 `merge`，避免一对多连接导致行数膨胀，这一点在客户画像工程中尤其重要。

运行：`python 01_customer_profile_tags.py`，结果输出到 `output/`。
