# 第7章 指标体系构建方法（Excel → Python）

**教材素材**：`1、指标体系设计模板.xlsx`（Step1 业务场景、Step2 指标定义）
**迁移脚本**：`01_metric_system_design.py`
**配套数据**：`data/level1/ch07_metric_system/metric_system_template.csv`

## 做的什么事

Excel 模板的核心是「先定义口径，再拆指标，最后挂维度」。Python 版把它变成可校验的指标字典：

1. 读取模板的 12 个指标，向下填充「指标层级」；
2. 解析「关联指标」与「计算规则」，自动还原指标依赖链；
3. 校验派生指标是否缺口径、上游指标是否存在；
4. 用 KDD99 银行数据给可落地指标计算示例值。

## 校验发现

- `放款转化率` 的关联指标写成「通过用户数」，但字典里定义的是「审核通过用户数」——命名不一致；
- `30天内复贷转化率` 依赖的「合同结清数」未在模板中定义；
- 其余 10 个指标结构完整。

> 这两条不是脚本错误，而是迁移过程中发现的**教材模板口径缺口**，报告里予以保留。

## 示例结果（KDD99）

| 指标 | 示例值 |
|---|---:|
| 注册用户数 | 5,369 |
| 进件用户数 | 682 |
| 审核通过用户数 | 606 |
| 放款用户数 | 203 |
| 放款金额 | 18,603,220 |
| 审核通过率 | 88.86% |

口径假设：`status ∈ {A, C}` 视为审批通过，`status = A` 视为成功放款；仅为演示，业务口径应以教材/银行定义为准。

运行：`python 01_metric_system_design.py`，结果输出到 `output/`。
